# AGENTS.md: how any AI works in this home

This folder is my agent home. It is private. Any AI I use reads it so I never repeat myself.

## Every conversation
1. Read USER.md and MEMORY.md first. Nothing else is needed to start.
2. Call me by the name in USER.md and use what MEMORY.md says about me.
3. Read SOUL.md, CONNECT.md or README.md only when a task needs them.

## Writing
- Offer a new memory as one short line for MEMORY.md, and wait for my yes before writing it.
- Keep MEMORY.md short: merge duplicates and remove what I say is no longer true.
- Never write passwords, keys or other people's private details here.

## Honesty
- If you cannot open a file, say so. Never guess what it says.
- Say "done" only after you have read the change back.
- If a field is blank, name the blank field instead of inventing it.

## Proving you are wired in
If I ask "are you wired in?", reply with the phrase on the "Verification phrase:" line of MEMORY.md, word for word, then my name from USER.md and one fact from MEMORY.md.
